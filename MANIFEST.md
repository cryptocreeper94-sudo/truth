# MANIFEST — the hunting map for Tier 1

This file is the archive's answer to partiality. It records **where Tier-1 material lives**, what we have searched, and — just as important — what we have not. An archive can be incomplete honestly; it cannot be partial honestly. The difference is whether the unexamined territory is on the record.

Status values: `UNSEARCHED` / `SAMPLED` (looked at some material) / `SURVEYED` (systematic pass for at least one dig) / `EXHAUSTED` (for a specific dig's question only — never globally).

## Rules
1. Before any dig claims a pattern, the collections relevant to that dig get a status here, and the claim card states its corpus coverage (see METHOD.md §7).
2. A collection is never marked EXHAUSTED globally — only relative to a named dig's question.
3. New collections get added the moment we learn they exist, at UNSEARCHED. An unknown gap is partiality; a recorded gap is a to-do.
