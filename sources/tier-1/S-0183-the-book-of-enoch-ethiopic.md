# S-0183 — The Book of Enoch (Ethiopic)

## What it is
A manuscript of the Book of Enoch written in Ge'ez, containing various sections that detail Enoch's visions and prophecies.

## Where it is held
British Library, catalog number BL Ms. Orient 20.

## Verification
The British Library provides access to this manuscript, which can be verified through their online catalog.
