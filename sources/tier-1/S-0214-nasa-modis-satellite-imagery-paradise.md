# S-0214 — NASA MODIS Satellite Imagery of Paradise (2018)

## What it is
Satellite imagery obtained from NASA's MODIS program, capturing the burn patterns associated with the Paradise fire in 2018.

## Where it is held
NASA, catalog number: PAR2018-MODIS-002.

## Verification
Verification can be done through NASA's MODIS website, which provides access to satellite imagery data.
