# S-0315 — NASA FIRMS Satellite Data

## What it is
A dataset providing satellite observations of wildfire incidents, including data related to Canadian wildfires from 2023 to 2026.

## Where it is held
NASA FIRMS, Catalog Number: FIRMS-2023-002.

## Verification
The dataset is accessible through the NASA FIRMS website, which provides real-time data on wildfire occurrences and assessments.
