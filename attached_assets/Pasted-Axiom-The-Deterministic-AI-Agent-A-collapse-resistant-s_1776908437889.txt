What is Axiom?
Axiom is the world's first fully deterministic AI agent. Every reasoning path is cryptographically verified, every response is certified, and every interaction is audit-logged with SHA-256 integrity chains.

No hallucination — responses are assembled from typed templates, not generated
No probabilistic drift — identical inputs produce identical outputs (AX-01)
No identity collapse — the Safety Envelope (Modules 35–42) fires before collapse, not after
Full audit trail — every decision traces back to a specific doctrine in the 42-doctrine Dissolution Ladder
Axiom is not an LLM wrapper. It is a new category of AI agent: a deterministic synthetic organism governed by formal rules.

Quick Start
Prerequisites
Node.js ≥ 20.0.0
PostgreSQL (optional — runs in memory-only mode without it)
Installation
git clone https://github.com/cryptocreeper94-sudo/DDA.git
cd DDA
npm install
Run (Demo Mode)
npm start
# → http://localhost:4200
Run (Full Stack)
Create a .env file with the following variables:

# Required for persistence
DATABASE_URL=postgresql://user:pass@host:5432/axiom

# Optional — enables voice
ELEVENLABS_API_KEY=sk_...
OPENAI_API_KEY=sk-...

# Optional — enables billing
STRIPE_SECRET_KEY=sk_live_...
STRIPE_PUBLISHABLE_KEY=pk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...

# Optional — enables telephony
TWILIO_ACCOUNT_SID=AC...
TWILIO_AUTH_TOKEN=...
TWILIO_PHONE_NUMBER=+1...
npm start
Run Tests
npm test                # All suites
npm run test:determinism  # 10,000-case AX-01 corpus
npm run test:collapse     # 500 adversarial cases
