### 2.3 Three-Tier Response Pipeline

This is the core HCI contribution — how users interact with the system:

**Tier 1 — Deterministic (D1–D5 satisfied):**
- Direct knowledge base lookup via pattern matching
- Response time: **<2ms**
- Confidence tag: `DETERMINISTIC` or `DETERMINISTIC_LEARNED`
- Zero hallucination possible by architecture
- Every response element traceable to a specific knowledge entry

**Tier 2 — Grounded:**
- When Tier 1 has relevant facts but no exact match
- Retrieves relevant facts from the knowledge base
- Passes them as context to an LLM for composition
- The LLM can ONLY compose from provided facts — it cannot introduce external knowledge
- Confidence tag: `GROUNDED`

**Tier 3 — Conversational:**
- Personal statements, greetings, meta-queries
- Falls through to LLM with no fact injection
- Clearly marked as conversational, not deterministic
- The system transparently tells the user which tier answered
