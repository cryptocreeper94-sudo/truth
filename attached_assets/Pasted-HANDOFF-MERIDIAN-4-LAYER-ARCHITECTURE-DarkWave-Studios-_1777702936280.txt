HANDOFF — MERIDIAN 4‑LAYER ARCHITECTURE
DarkWave Studios — For Claude Review

SUMMARY:
Meridian is a four‑layer deterministic energy‑routing architecture designed to coordinate ambient harvesting, burst‑mode storage, mesh‑based relay logic, and directional wireless power delivery.

LAYER 1 — MERIDIAN CORE (MC)
Defines the foundational energy‑coordinate system. Establishes node identity, spatial orientation, charge‑state representation, and deterministic timing primitives. Provides the universal reference frame for routing, harvesting, and alignment across the mesh.

LAYER 2 — MERIDIAN FLOW ENGINE (MFE)
Implements energy‑flow logic. Converts charge‑state data into deterministic routing decisions. Manages burst‑mode scheduling, threshold evaluation, and directional flow selection. Ensures predictable, loss‑bounded energy propagation across the network.

LAYER 3 — MERIDIAN MESH FABRIC (MMF)
Handles multi‑hop coordination. Maintains routing tables, link‑state awareness, and neighbor‑graph topology. Supports bi‑directional energy movement, relay participation, and mesh‑level optimization. Integrates DRMA logic for packet‑like energy handling.

LAYER 4 — MERIDIAN TRANSMISSION LAYER (MTL)
Executes physical energy delivery. Controls beam steering, RF emission shaping, safety gating, and closed‑loop confirmation. Aligns with DWER for deterministic wireless power transfer. Ensures compliance with directional, range‑bounded energy output.

ARCHITECTURAL PRINCIPLE:
Each layer is independent but vertically coupled. MC defines the coordinate system, MFE defines the flow, MMF defines the path, and MTL defines the physical emission. Together they form a deterministic, self‑governing wireless‑energy infrastructure.
