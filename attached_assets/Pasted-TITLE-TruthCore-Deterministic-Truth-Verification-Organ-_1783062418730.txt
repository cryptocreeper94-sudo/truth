SECTION 2 — HIGH-LEVEL DESCRIPTION OF TRUTHCORE
------------------------------------------------------------
TruthCore is a deterministic system that evaluates ANY user-provided input:
- text claims
- quotes
- rumors
- news headlines
- images (metadata + signature verification)
- documents
- social media posts
- “I heard this on the internet” statements

TruthCore returns one of five deterministic outputs:
- TRUE — matches verified fact in K
- FALSE — contradicts verified fact in K
- UNKNOWN — no matching fact in K
- UNVERIFIABLE — insufficient data in K
- CONFLICTING — verified sources disagree

Every output includes a provenance path:
- source fact ID
- document reference
- timestamp
- verification chain
- confidence markers (deterministic, not probabilistic)

TruthCore NEVER guesses, estimates, or assigns probabilities.

SECTION 3 — ARCHITECTURE OVERVIEW
------------------------------------------------------------
TruthCore extends DLA and AXIOM using the following layers:

1. **Input Normalization Layer**
   - Canonicalizes user input into structured claims.
   - Extracts entities, events, dates, and relationships deterministically.

2. **Deterministic Lookup Layer**
   - Queries the verified fact corpus (K).
   - Queries verified image/document signature registries.
   - Queries verified event timelines.
   - All lookups are deterministic and bounded.

3. **Deterministic Matching Layer**
   - Matches normalized claims against K.
   - Uses deterministic rule-based matching (no embeddings, no neural nets).
   - Produces one of the five truth states.

4. **Governance Layer (Lume Organism)**
   - Governs presentation, not content.
   - Ensures consistent tone, register, and template.
   - Cannot introduce new facts (D4).

5. **Hard Constraint Layer**
   - Enforces:
     - Knowledge boundary (cannot answer outside K)
     - Correction integrity (conflicts logged, not overwritten)
     - Provenance traceability (mandatory)

6. **Output Layer**
   - Returns deterministic truth classification + provenance.
