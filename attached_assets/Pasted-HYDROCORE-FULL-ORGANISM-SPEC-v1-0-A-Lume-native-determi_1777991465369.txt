1. LUME-HYDRO CORE — THE 4 HYDROCORE PRIMITIVES
============================================================
These are the four irreducible flows HydroCore governs.

1. PRESSURE FLOW
   - Pressure, head, differential, hydraulic potential.
   - Governs routing, force, and system stability.

2. VOLUME FLOW
   - Flow rate, discharge, throughput, saturation.
   - Governs distribution, availability, and load.

3. PURITY FLOW
   - Contamination, turbidity, pathogens, chemical load.
   - Governs safety, potability, and filtration needs.

4. THERMAL FLOW
   - Temperature, thermal gradients, freeze/thaw states.
   - Governs viscosity, phase change, and flow behavior.

Each primitive is a continuous field over space and time.

============================================================

- Channel geometry, pipe data, watershed data
- 42 node states
- System constraints (capacity, safety limits)
- Targets (distribution points, reservoirs, outlets)

Outputs:
- Optimal routing path
- Flow adjustments
- Pressure balancing
- Purity warnings
- Thermal risk alerts
- System optimization recommendations

Deterministic Rules:

1. HARD CONSTRAINT ENFORCEMENT
If any node crosses critical threshold:
- Halt routing through that segment
- Propose alternate flow paths
- Escalate warnings

2. RISK-WEIGHTED FLOW SCORING
Score = f(Risk, Efficiency, Stability, Purity)

3. PRESSURE EQUALIZATION
HydroCore balances pressure across segments to avoid bursts or collapse.

4. PURITY PROTECTION
Routes avoid contaminated segments unless filtered.

5. THERMAL SAFETY
Avoids freeze zones, high thermal shock zones, and viscosity extremes.

6. DYNAMIC RE-EVALUATION
Recompute all 42 nodes continuously.
