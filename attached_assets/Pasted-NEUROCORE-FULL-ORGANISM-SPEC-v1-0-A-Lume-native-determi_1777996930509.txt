Requirements:
- Renderable in 2D and 3D.
- Preserve 4/42 structure.

============================================================
Base frame:
- Center: 4-axis cognitive core (Attention, Intention, Emotional, Cognitive Load).
- Surrounding ring: 42 nodes, grouped by primitive.
- Outer field: overlays for drift, pressure, and resilience.

Coordinate system:
- 2D: polar coordinates for ring (angle = node index, radius = state).
- 3D: Cartesian for extrusion (Z = time or depth).

============================================================
2. CORE — 4 PRIMITIVE AXES
============================================================
Axes (clockwise from top in 2D):

- Up (0°): ATTENTION FLOW
- Right (90°): INTENTION FLOW
- Down (180°): EMOTIONAL FLOW
- Left (270°): COGNITIVE LOAD FLOW

Each axis:
- Length: aggregate primitive health (−1.0 to +1.0).
- Color: fixed per primitive.
- Thickness: volatility (rate of change).

Suggested palette:
- Attention: bright cyan
- Intention: gold/amber
- Emotional: magenta/pink
- Cognitive Load: deep violet/indigo

Core shape:
- Axes form a diamond or cross.
- A small central polygon (4-sided) connects axis tips, showing overall cognitive balance.

============================================================
Ring radius:
- Base radius R_base.
- Node radial offset encodes node state.

Angular segmentation:

- Nodes grouped in contiguous arcs by primitive:

Groups:
- Attention (A1–A10): 10 sectors
- Intention (I1–I10): 10 sectors
- Emotional (E1–E11): 11 sectors

Ordering (clockwise from top):
- Start at 0° with A1 → A10

- Then L1 → L11

- Small circles or hexagons.
- Node radius: alert level or importance.
- Fill color: state band
  - Cool/bright: favorable

  - Orange: caution
  - Red: critical

Radial mapping:
- s ∈ [−1.0, +1.0]
- s = +1.0 → slightly outside R_base (healthy outward pulse)
- s = 0.0 → on R_base
- s = −1.0 → pulled inward toward core (collapsing)
