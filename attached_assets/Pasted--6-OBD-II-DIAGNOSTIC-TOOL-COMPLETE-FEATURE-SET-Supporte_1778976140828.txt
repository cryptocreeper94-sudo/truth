### Cryptographic Anchoring (NEW — just built)
Every condition report now:
1. Computes SHA-256 hash via Web Crypto API
2. Generates a UUID certificate ID
3. POSTs to CAL (enterprise) or Trust Layer (consumer)
4. Displays hash fingerprint + certificate ID + anchor status on report
5. If ledger is offline, shows "HASH COMPUTED · LOCAL" — hash is still valid

File: src/telemetry/AnchorService.ts
- computeSHA256() — deterministic JSON serialization + Web Crypto digest
- anchorReport() — routes to CAL or Trust Layer based on deployment context
- verifyReport() — recomputes hash for tamper detection
