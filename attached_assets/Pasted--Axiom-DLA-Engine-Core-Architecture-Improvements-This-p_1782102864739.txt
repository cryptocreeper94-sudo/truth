## Proposed Changes

We will systematically upgrade the DLA engine across four critical systems to increase determinism and fallback tracking.

### 1. Pre-Decomposition Build Step

#### [NEW] `D:\dda\scripts\predecompose-packs.mjs`
A build-time script that preemptively analyzes the dynamic domain JSON packs and compiles them into a flattened `data/fact-cache.json` to bypass runtime decomposition latency.

#### [MODIFY] `D:\dda\src\composition\composition-engine.js`
Update the runtime engine to detect and load `this.factCache?.[domain]?.[topicKey]`. If a cache hit occurs, it skips decomposition.

Add the `"predecompose": "node scripts/predecompose-packs.mjs"` command to the `scripts` block to automate cache generation during the CI pipeline.

### 2. Fallback Telemetry

#### [MODIFY] `D:\dda\src\engines\cognitive-engine.js`
Wrap the core execution in a strict `try/catch`. On failure, invoke a non-blocking `this._logFallback({domain, intentKey, error, timestamp})` method that appends the trace to `logs/composition-fallbacks.log`.

#### [NEW] `D:\dda\scripts\fallback-report.mjs`
A utility script that parses `composition-fallbacks.log`, groups failures by `domain` and `intentKey`, and outputs the top 10 most frequent engine faults for rapid debugging.

---

### 3. Thesaurus Expansion

#### [NEW] `D:\dda\data\domain-thesaurus.json`
Create a localized, domain-specific synonym map (e.g., `trust vault` -> `Axiom42Suite`, `meridian` -> `ecosystem core`) to prevent generic WordNet drift.

#### [MODIFY] `D:\dda\src\composition\composition-engine.js`
Intercept synonym lookups to check `domain-thesaurus.json` first, strictly prioritizing local ontology before falling back to the generic `moby-thesaurus` or `WordNet` structures.

### 4. Correction Confidence Layer & Tone

#### [MODIFY] `D:\dda\src\knowledge\learning-memory.js`

#### [NEW] `D:\dda\scripts\audit-corrections.mjs`
A script that lists unconfirmed vs. confirmed corrections side-by-side to allow the Governance Authority to manually review the learning memory's drift.

#### [MODIFY] `D:\dda\src\composition\tone-adapter.js`
