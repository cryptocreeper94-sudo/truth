============================================================

- Each axis is a vector of “flow pressure” (how strongly that primitive pushes toward risk or opportunity).

- 42 nodes arranged in a ring.
- Each node holds a normalized state: -1.0 (worst) to +1.0 (best).

Fractal Behavior:
- Any segment of the environment (1 km, 10 minutes, etc.) can be represented as its own 4/42 micro-organism.
- Verdara is recursive and scale-invariant.

============================================================

- Waypoints, bailout points
- 42 node states
- Time budget
- User profile (fitness, gear, risk tolerance)

Outputs:
- Recommended route segment
- Pace envelope
- Warnings
- Opportunities
- Adaptation suggestions

Deterministic Rules:

1. HARD CONSTRAINT ENFORCEMENT
If any node crosses critical threshold:
- Halt forward progress on that path
- Propose alternate routes
- Escalate warnings

2. RISK-WEIGHTED PATH SCORING
Score = f(Risk, Effort, Progress, Resilience)

3. TIME-WINDOW ALIGNMENT
Align movement with safe weather windows.

4. RESOURCE-AWARE ROUTING
Ensure access to water, shelter, bailout points.

5. DYNAMIC RE-EVALUATION
Recompute all 42 nodes continuously.

6. USER-ALIGNED RISK ENVELOPE
Risk profile modifies thresholds but logic remains deterministic.
