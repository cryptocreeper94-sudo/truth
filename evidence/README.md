# Physical Evidence Case Files

This directory contains one case file per experiment or documented physical observation.  It is part of the Truth monorepo; it is not a separate application or archive.

## Workflow

1. **Open a case file** using the schema in `PHYSICAL_EVIDENCE.md`.
2. **Preserve the earliest available source** with its URL, retrieval timestamp, and file hash when possible.
3. **Classify every source** before relying on it.  A viral video, blog post, news article, technical report, raw dataset, and instrument log do not carry the same evidentiary role.
4. **Extract claims neutrally.**  Record what the source says, who says it, and where in the artifact it appears.  Do not convert a speaker's conclusion into an observation.
5. **Recover underlying sources.**  A commentary clip can point to a report; the report can point to a dataset; the dataset or original measurement is the evidence to analyze.
6. **Record methods and missing controls.**  Distance, elevation, instrument calibration, weather, editing, and alignment details must be explicit.
7. **Write competing predictions before interpreting the result.**
8. **Link replications, criticisms, corrections, and opposing sources** to the same case.
9. **Assign a status only after checking completeness and controls.**  Missing information produces an `INCOMPLETE` or `INCONCLUSIVE` status, not a forced conclusion.

## Research notes

Discovery notes should record:

- Search date
- Search terms
- Archive, database, or repository searched
- Candidate sources found
- Sources excluded and why
- The next underlying source to locate

The purpose is to preserve the research path.  A future researcher should be able to repeat the search without relying on memory of a conversation or a disappearing search result.

## Agenda and framing

This project can document a source's declared interests, affiliations, funding disclosures, editorial choices, and observable framing.  It must not state an author's private motive as fact without independent evidence.

- **Documented:** explicitly stated or directly observable in the source
- **Plausible but unverified:** a reasonable hypothesis that needs evidence
- **Unknown:** no reliable basis for the inference

Disagreement with a result is not, by itself, evidence of deception.
