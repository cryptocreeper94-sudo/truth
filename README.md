# THE STRATA ARCHIVE

**A provenance-first archive of historical claims, the sources behind them, and the documented gaps between them.**

Curated by Jason Andrews / DarkWave Studios LLC. Companion project to the book *Through The Veil* ("The Lying Pen").

---

## If you are reading this without context

This is not a collection of things we believe. It is a **case file system**.

The working thesis — argued at book length elsewhere — is that portions of the historical record have been deliberately altered, and that coordinated falsehood leaves structural fingerprints that honest error does not: identical wording across "independent" sources, narratives that flip in lockstep at specific dates, archives that burn on schedule. This archive exists to catalog claims and sources with enough provenance discipline that those patterns become **visible and checkable** rather than merely asserted.

The archive's credibility rests on one thing: **it labels its own uncertainty honestly.** A claim marked SPECULATIVE here is speculative. A link marked THEMATIC is not corroboration. If you find an entry that violates its own tags, that entry is wrong and should be fixed — the method outranks any conclusion.

## The three iron rules

1. **Every claim carries a confidence tag.** DOCUMENTED / CONTESTED / SUPPRESSED-IF-TRUE / SPECULATIVE. No untagged claims. Ever.
2. **Every link between claims is typed and tagged too.** A connection is itself a claim. "These sources use identical phrasing" (documented) is not the same kind of link as "these events feel related" (speculative). Speculative links never count as corroboration.
3. **Motive is argued last, from documented links only.** "Who benefits" is a conclusion the evidence earns, never an assumption the evidence is arranged around.

## Structure

```
README.md          — this file: what the archive is and the rules it lives by
METHOD.md          — the full specification: tiers, tags, link types, ID scheme
sources/tier-1/    — source records: physical survivors (maps, first editions,
                     patents, court records, coins, buildings, ship manifests)
claims/            — claim cards: one file per claim, tagged and sourced
links/             — typed connections between claims/sources
digs/              — dig sites: index pages that gather the claims, sources,
                     and links around one question
```

We are currently building **Tier 1 only** — the physical survivors, the material hardest to retroactively edit. Other tiers (contemporary records, official narratives as exhibits, testimony, the absence catalogue) are specified in METHOD.md and will open later. The archive expands like an excavation: from a proven trench outward.

## What this archive is not

- Not a wiki of conclusions. Conclusions live in the book; evidence and its sorting live here.
- Not a place where a pile of speculative links adds up to proof. It doesn't, and the tags exist so it can't.
- Not finished. Entries get demoted as well as promoted. The willingness to rule against ourselves is the feature.
